Mesocycle
Cycle Settings
Rotations per mesocycle
A rotation = completing every routine in the sequence once.
Times to repeat this mesocycle
0 = repeat indefinitely.
Deload after each mesocycle
Deload method
Deload weight drop (%)
Cuts this % off the "starting point for the next mesocycle" weight below — not the heaviest cycle of this mesocycle — so the deload's own weight is based on the same reference point the next mesocycle will resume from.
Fewer sets during deload (optional)
Drops this many sets off the end of each exercise, on top of the weight cut. 0 = same set count, lighter weight only.
Reduce sets to
Target effort (RIR)
Only the number of sets drops. Weight and reps come from the "starting point for the next mesocycle" setting below — not the heaviest cycle of this mesocycle — so the deload is never accidentally programmed too heavy. This RIR is shown as guidance at the top of each deload workout; it isn't mechanically enforced, the same way your normal RIR target isn't.
Starting point for the next mesocycle
This also decides what weight/reps the deload itself is based on (the weight method cuts a % off it, the sets method uses it as-is). "Continue from deload weights" has nothing to resolve to yet at that point, so it falls back to your pre-deload weights automatically.
Which rotation to resume from
Uses the weights you started that rotation at, averaged with the rotations either side of it and sanity-checked against the whole mesocycle — e.g. rotation 4 of 6 gives you two rotations' worth of room to progress past your previous peak.
Ramp RIR across the mesocycle
RIR target on the last rotation
Starting RIR cap
Rotation 1 starts at this RIR (or lower, if the mesocycle is short) and ramps down evenly each rotation to your last-rotation target. Shown at the top of each meso-linked workout.
Predict today's rep target from RIR
Weight is never touched by this — it stays exactly what normal progression has it at, so you're not re-loading plates or swapping dumbbells just to hit a target RIR. Instead, the pre-filled rep count adjusts: N reps short of the true failure count you hit at this weight last time, where N is today's target RIR (that's the literal definition of RIR). Weight still increases the normal way, whenever you push past your rep ceiling. Needs at least one completed mesocycle pass to have a true-failure reference to work from; until then it has no effect.
Early deload detection
Exercises declining (threshold)
Triggers early if this many exercises' top sets decline against their last two sessions, or if effort is already hitting your final-rotation RIR target well ahead of schedule — before the mesocycle's planned rotation count runs out.
Rep Ranges
Only applies to this position in this mesocycle's sequence — the routine's own default (used everywhere else) is unaffected.
