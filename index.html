📈 Training ▸
Volume Landmarks ▸
Weekly working-set landmarks per muscle — MV (maintenance), MEV (minimum effective), MAV (maximum adaptive), MRV (maximum recoverable). Used to judge whether a muscle's weekly volume (in Review) is too low, in the growth zone, or past what you can likely recover from. Defaults are a reasonable starting point, not a prescription — tune them to your own recovery over time.

🔁 Rotation & Repeats ▸
Rotations per mesocycle
A rotation = completing every routine in the sequence once. Paces the volume and RIR ramps (early rotations near MEV/higher RIR, this one at MAV/your final RIR target) — with deload enabled, it's not a hard cutoff: training keeps going past it until a real decline shows up, gaining a bit more volume each extra rotation, up to each muscle's own MRV.
Times to repeat this mesocycle
0 = repeat indefinitely.
📊 Volume Automation ▸
Auto Volume Distribution
Every routine starts each session at ZERO sets — the app fills in how many sets each exercise gets, purely from each muscle's rolling weekly target minus what's actually been logged in the last 7 days. Falls behind pace (fewer workouts one week, more the next, a late-week catch-up session) and it front-loads the remaining sets onto the soonest upcoming sessions rather than spreading evenly, capped at a max per muscle per workout. Can leave a given exercise at 0 sets for a session if its muscle's share went to a sibling exercise instead — add a set manually if you want it anyway. Applies during the training phase only; deload keeps its own existing cut logic.
Max total sets per session
Off by default — with the per-muscle cap already bounding any one muscle and catch-up already spread/front-loaded rather than dumped in one session, there's no total that's safe to assume for everyone. Set a number here only if you want a hard ceiling on total sets in a single session; if several muscles are behind at once their shares scale down proportionally to stay under it.
Continuous Volume Mode
An alternative to the 2-muscle Priority/Back-Burner cap (kept separately below) — every muscle CAN run its own MEV→MRV progression and its own RIR trajectory, but only a limited number are ever actively pushing at once (below) — everyone else holds at MEV maintenance. Which muscles are active auto-rotates based on readiness (headroom left before their own MRV, plus freshness), not a fixed pick. For a set trained by more than one muscle, the exercise's primary muscle's RIR governs the whole set. Used by Auto Session; doesn't change fixed-routine sessions.
Max muscles actively pushing at once
Defaults to 3 — trying to push every muscle toward MRV simultaneously just means each one hits its per-session cap and gets diluted, never really achieving concentrated overload. Auto-rotates which muscles hold this slot as readiness shifts session to session.
Weekly set budget (Auto Session)
Off by default. If several actively-pushing muscles could all use more at once, set a total weekly sets figure here and Auto Session splits it by readiness instead of letting every active muscle's raw target stack unchecked.
🪫 Deload ▸
Deload after each mesocycle
Deload method
Deload weight drop (%)
Cuts this % off the "starting point for the next mesocycle" weight below — not the heaviest cycle of this mesocycle — so the deload's own weight is based on the same reference point the next mesocycle will resume from.
Fewer sets during deload (optional)
Drops this many sets off the end of each exercise, on top of the weight cut. 0 = same set count, lighter weight only.
Target effort (RIR)
Set count is auto-derived from each exercise's muscle MV (maintenance volume), split across sibling exercises training that muscle in this routine — not a number you set. Weight and reps come from the "starting point for the next mesocycle" setting below — not the heaviest cycle of this mesocycle — so the deload is never accidentally programmed too heavy. This RIR is shown as guidance at the top of each deload workout; it isn't mechanically enforced, the same way your normal RIR target isn't.
Starting point for the next mesocycle
This also decides what weight/reps the deload itself is based on (the weight method cuts a % off it, the sets method uses it as-is). "Continue from deload weights" has nothing to resolve to yet at that point, so it falls back to your pre-deload weights automatically.
Which rotation to resume from
Uses the weights you started that rotation at, averaged with the rotations either side of it and sanity-checked against the whole mesocycle — e.g. rotation 4 of 6 gives you two rotations' worth of room to progress past your previous peak.
Early deload detection
Exercises declining (threshold)
This is now the only thing that ends a deload-enabled mesocycle's training phase — there's no separate scheduled deload. Main driver: this many exercises' top sets declining against their last two sessions (checked every workout, including past the rotation count above). Effort hitting your final RIR target ahead of schedule (before the rotation count above) is a second, weaker signal — it always asks first regardless of the mode above, since training that hard early can just be your own choice rather than a sign the pass is done. Only when it lines up with an actual decline does the mode above decide whether to ask or deload automatically.
🎚️ RIR Ramp ▸
Ramp RIR across the mesocycle
RIR target on the last rotation
Starting RIR cap
Rotation 1 starts at this RIR (or lower, if the mesocycle is short) and ramps down evenly each rotation to your last-rotation target. Shown at the top of each meso-linked workout.
Predict today's rep target from RIR
Weight is never touched by this — it stays exactly what normal progression has it at, so you're not re-loading plates or swapping dumbbells just to hit a target RIR. Instead, the pre-filled rep count adjusts: N reps short of the true failure count you hit at this weight last time, where N is today's target RIR (that's the literal definition of RIR). Weight still increases the normal way, whenever you push past your rep ceiling. Needs at least one completed mesocycle pass to have a true-failure reference to work from; until then it has no effect.
Rep Ranges
